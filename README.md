# Scripture - KJV Bible Reading Platform

A modern, elegant Bible reading and study platform with the King James Version (KJV).

## Features

- 📚 Complete 66-book Bible structure
- 🌓 Light/Dark mode with system preference
- 🔍 Powerful search with verse reference support
- 📌 Bookmark verses
- 📝 Take notes on verses
- 📅 Daily verse
- ⚙️ Customizable reading settings (font size, line height, width)
- 📱 Fully responsive design

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React Icons
- kjv-bible npm package
- localStorage for persistence
